### 卷积与池化

```python
from torch.nn import Module,Conv2d,ReLU,MaxPool2d,init

class CNN(Module):

    def __init__(self, n_channels):
        super().__init__()
        # 卷积层
        self.hidden1 = Conv2d(n_channels, 32, (3,3))
        # 初始化权重
        init.kaiming_uniform_(self.hidden1.weight, nonlinearity = 'relu')
        # 设置激活函数
        self.act1 = ReLU()
        # 池化层(池化大小，池化步长)
        self.pool1 = MaxPool2d((2,2), stride=(2, 2))


        # 卷积层2
        self.hidden2 = Conv2d(32, 32, (3,3))
        # 初始化权重
        init.kaiming_uniform_(self.hidden2.weight, nonlinearity = 'relu')
        self.act2 = ReLU()

        # 池化层2(池化大小，池化步长)
        self.pool2 = MaxPool2d((2,2), stride=(2, 2))
```

### 前向传播

模型架构：定义了前向传播的路径和操作顺序

前向传播：路径上执行具体的数据处理，层与层之间的数据传递和参数计算

```python
    def forward(self, X):
        # 第一次卷积池化
        X = self.hidden1(X)
        X = self.act1(X)
        X = self.pool1(X)
        # 第二次卷积池化
        X = self.hidden2(X)
        X = self.act2(X)
        X = self.pool2(X)
        # 扁平化
        X = X.view(-1, 5*5*32)
        # 全连接层的隐藏层
        X = self.hidden3(X)
        X = self.act3(X)
        # 输出层
        X = self.hidden4(X)
        X = self.act4(X)
        return X
```

### 后向传播
计算误差(损失函数)
- 回归问题 -> 均方误差
- 分类问题 -> 交叉熵损失

反向传播和参数更新(优化器)
梯度下降 -> 收敛慢，陷入局部最优
Adam优化器 -> 通过自适应学习率调整，更快到全局最优或者较优的解
